# Контент-ателье

Статический сайт без зависимостей, API-ключей и сборки. Бриф по темам создаёт редактируемые редакторские заготовки. Фото загружается локально. Посты, сторис и три слайда карусели экспортируются по одному в PNG. Тексты экспортируются в TXT, проект — в JSON. Данные сохраняются в localStorage; фото остаётся в памяти вкладки.

Разместите index.html в корне GitHub Pages. Workflow .github/workflows/pages.yml публикует main. В Settings → Pages выберите GitHub Actions.

Сайт не генерирует фотографии и не публикует в соцсети. Перед публикацией проверьте и дополните тексты. При открытии файла index.html локально основные функции работают без интернета.
