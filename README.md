# IRINA / STUDIO — content portal

Контент-план для @permanent_irina.qs на 16–29 ноября 2026.

Подготовлены 14 публикаций: 8 серий сторис по 3 кадра, 4 карусели по 5 слайдов и 2 поста, всего 46 текстовых кадров. Для каждой публикации есть цель, метрика, готовый текст и задание на оформление. Подписи к ленте включены. Текстовый план и исследование можно скачать на сайте.

Исследование актуально на 15 ноября 2026: официальные материалы Meta, FDA, Cleveland Clinic и AAD. Точные прогнозы алгоритмов 2027 не заявляются; направления 2027 помечены как гипотезы. Позиционирование «врач, 8 лет, Минск» предоставлено владельцем аккаунта и не проверено независимо.

Изображения пока не созданы; одобрение изображений, серверное хранение, Instagram и автоматическое расписание не подключены. Публикации в Instagram не выполняются. Замечания в интерфейсе сохраняются в браузере, доступны для скачивания JSON.

GitHub Actions публикует статический index.html в Pages. Полный план доступен внутри сайта без внешних библиотек.
