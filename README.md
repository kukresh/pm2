# PMU Studio — Gemini

Статический сайт: контент-план на неделю, редактор постов/сторис/каруселей и генерация фото через собственный API-ключ Gemini. Установка зависимостей и сборка не нужны.

## Загрузка на GitHub
1. Создайте репозиторий на GitHub с основной веткой main.
2. Распакуйте архив и загрузите содержимое папки pmu-studio-github в корень репозитория. Обязательно сохраните папку .github/workflows и файл .nojekyll. Через git: git add . затем commit и push в main.
3. Откройте Settings → Pages → Build and deployment → Source → GitHub Actions.
4. Во вкладке Actions дождитесь успешного Publish GitHub Pages. При необходимости запустите workflow вручную через Run workflow.
5. Ссылка появится в Settings → Pages и в результате workflow.

## Генерация изображений
1. Откройте Gemini и лимиты.
2. Получите собственный API-ключ в https://aistudio.google.com/api-keys . Проверьте доступ к image-модели и квоту/оплату API.
3. Введите ключ и модель (по умолчанию gemini-2.5-flash-image), нажмите Применить ключ.
4. В студии введите описание и нажмите Сгенерировать фото.

Ключ находится только в памяти открытой вкладки. После перезагрузки его нужно ввести повторно. Он передаётся Google в заголовке x-goog-api-key, не в URL. Не вставляйте ключ в исходники, коммиты, README или GitHub Secrets. Для общего корпоративного ключа нужен отдельный сервер; GitHub Pages серверный код не запускает. Используйте личный ограниченный ключ и ограничения доступа Google по возможности.

## Лимиты
План создаётся локально: 3 публикации на неделю. Выберите предел 1, 2, 3 или 5 попыток за сеанс. Одно фото можно использовать повторно; карусель использует одно фото для всех слайдов. Параллельные запросы и автоматические повторы отключены. Счётчик сайта — локальный ограничитель, не фактический остаток квоты Google. При 429 генерация останавливается до проверки квоты и обновления вкладки. Бесплатный лимит 0 не исправляется ожиданием или новым ключом того же проекта.

## Локальный просмотр
Откройте index.html в браузере. Если браузер ограничивает запросы с file://, используйте любой локальный HTTP-сервер, например python -m http.server 8000, и откройте http://localhost:8000.

## Ограничения
Нужен интернет: шрифты, Tailwind CSS и иконки загружаются с CDN. Контент-план использует готовые локальные шаблоны. Instagram-раздел хранит черновики и не публикует их. Сгенерированные изображения сохраняйте через Скачать PNG: кэш фото работает только в памяти вкладки. Результаты нейросети не следует выдавать за реальные работы мастера.

## Проверка
Проверены синтаксис JavaScript, формирование запроса Gemini, обработка ответа с картинкой и ошибки 429. Реальный вызов Google не проверен без API-ключа владельца.
